# אינדקס — פלטפורמת אינדקס עסקים

פלטפורמת מרקטפלייס/אינדקס עסקים, עברית-first (RTL), בנויה על Next.js 16, TypeScript, Tailwind v4 ו-Supabase.

## הרצה

```bash
npm install
npm run dev
```

האתר עולה ב-http://localhost:3000 **בלי צורך במסד נתונים**. בהיעדר חיבור ל-Supabase שכבת הנתונים נופלת לתוכן ההדגמה שב-`src/data/seed.ts`.

## חיבור ל-Supabase

1. `cp .env.example .env.local` ומילוי הערכים.
2. הרצת המיגרציות מ-`supabase/migrations/` **לפי הסדר** — כל קובץ הוא idempotent וניתן להרצה חוזרת.

```bash
supabase db push
```

או העתקה של כל קובץ ל-SQL Editor והרצה לפי מספור.

> ⚠️ המיגרציות נכתבו ונבדקו בקריאה בלבד — הן טרם הורצו מול Postgres. יש להריץ אותן קודם על סביבת בדיקה.

## החלטות תכנון מרכזיות

**מערכת העיצוב היא טוקנים בלבד.** אין צבע, רדיוס או צל שנכתב ישירות ברכיב — הכל דרך `@theme` ב-`globals.css`. זה מה שיאפשר למנהל לשנות ערכת צבעים מלוח הבקרה בלי דיפלוי.

**מצב המסננים חי ב-URL.** תוצאות מסוננות ניתנות לשיתוף, כפתור "אחורה" עובד, והשרת מרנדר את התוצאות הנכונות מיד.

**RLS על כל טבלה, ברירת מחדל "אסור".** בנוסף, הרשאות ברמת העמודה: בעל עסק לא יכול לשנות את הסטטוס, ה-tier או הדירוג של עצמו.

**דירוגים מנורמלים-לאחור.** `rating_avg` ו-`review_count` יושבים על שורת העסק ומתוחזקים בטריגר — חישוב `AVG` בכל טעינת רשימה הוא הדבר הראשון שנשבר בקנה מידה.

**חיפוש בעברית** משתמש בקונפיגורציית `simple` + `pg_trgm`, לא ב-stemmer אנגלי שמשחית מילים עבריות.

## מה עדיין חסר

ראו את הסיכום בסוף הסשן. בקצרה: לוח בקרה לאדמין, לוח בקרה לבעל עסק, אימות משתמשים, עמודי קטגוריה ובלוג, וחיבור שכבת ה-repo ל-SQL בפועל.
