# Rentus — דוח QA למובייל

תאריך: 21.08.2026  
סביבת בדיקה: Next.js מקומי, Chromium דרך Playwright  
מצב הרשאה: אורח ללא session של בעל עסק או איש צוות

## תוצאה

- 36 מתוך 36 מסלולי UI ומצבי מערכת עברו render ב־390×844 ללא גלילה אופקית.
- 50 מתוך 50 שילובי viewport ואזור עברו בדיקת render, תוכן ו־overflow.
- עמוד הבית, רשימת החברות ופרופיל חברה נבדקו בפועל בכל עשרת הגדלים.
- `/business/dashboard` וכל `/admin/*` הפנו ל־`/login` בכל עשרת הגדלים, כמצופה מאורח.
- אין שגיאות console בסשן ה־QA.
- `npm run lint` ו־`npm run build` עברו; ה־build יצר 44 עמודים ומסלולים.

## אינטראקציות ונגישות

- תפריט המובייל ומגירת הסינון לוכדים focus, עוטפים `Tab`, נסגרים ב־`Escape` ומחזירים focus ל־trigger.
- הפופ־אפ נועל גלילת רקע, ממקד את כפתור הסגירה ומציג מודעת תמונה ללא אזור תוכן ריק.
- אקורדיוני הפוטר נפתחים דרך `details/summary`, והקישורים המשפטיים נשארים נגישים למקלדת ולקורא מסך.
- כפתורי המפתח שנמדדו ב־320px: תפריט 44×44, סינון גובה 44, נגישות 44×44, חיוג בכרטיס חברה 44×44.
- כפתור הנגישות אינו חופף לטקסט זכויות היוצרים או לפעולות הקבועות בתחתית.
